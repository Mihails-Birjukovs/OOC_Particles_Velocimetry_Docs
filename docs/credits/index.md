# Credits & data provenance

The experimental datasets and the software used to process them have **different rights holders and contributors**. They must not be conflated.

## Experimental data and measurements — ISSP

**Data owner:** **Institute of Solid State Physics (ISSP), University of Latvia**.

**Principal experimental contributors:** **Betija Ziediņa** and **Gunita Kojāne**. All experimental credit belongs to ISSP. The experimental data were shared with Mihails Birjukovs for code development, verification and documentation examples; that collaboration does not transfer ownership of the data.

## Software and documentation — INM

**Code and documentation development:** **Mihails Birjukovs**, **Institute of Numerical Modelling (INM), University of Latvia**.

The current OOC Particle Flow v5.2 source, tests, documentation and the public website were developed by Mihails Birjukovs. The source descends from his independently developed [earlier OOC particle-flow CNR-boost framework](https://github.com/Mihails-Birjukovs/OOC_particle_flow_CNR_boost_for_PIV).

The original software and documentation are MIT-licensed, **copyright © 2026 Mihails Birjukovs**; the earlier repository carries its own 2024 MIT copyright notice. Please preserve notices when redistributing software.

## Publication permission for the Run 1 figure

ISSP specifically authorized the **reduced-resolution Run 1 montage** used as an illustrated example in this website, including for Betija Ziediņa's use of the documentation.

**This is permission to publish that one example here, not a general data license.** The figure remains **all rights reserved**, is excluded from the software MIT license, and is labeled as historical v5 processing rather than fresh v5.2 output. The full TIFF sequence, processed archives and numerical measurement fixtures are not published or licensed for general reuse.

For individual figure provenance see the [Run 1 case study](../tutorials/real-run1.md). For rights and reuse restrictions see [Licensing](../licensing/index.md).

## Scientific publications

The authorship of a collaborative scientific paper is defined by that paper's author list, not by ownership of the notebook code or of the later experimental datasets. The [Research & References](../research/index.md) page links the relevant literature and journal-published OOC flow paper.
